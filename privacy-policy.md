Privacy Policy – Artur4ik Proxy

Artur4ik Proxy does not collect, store, or transmit any personal data.

The extension only changes the browser proxy settings locally on the user's device using the Chrome Proxy API.

To display the current external IP address, the extension sends a request to the public API service https://api.ipify.org. This request is used only to retrieve the IP address and is not used for tracking, analytics, or data collection.

No browsing history, personal information, or authentication credentials are collected or stored by the extension.

All proxy credentials used by the extension are stored locally within the extension and are only transmitted to the configured proxy server for authentication.
